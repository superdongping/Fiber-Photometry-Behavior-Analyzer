# Historical versions from SongLabDLC

`SongLabDLC_Fiber_photometry_V4_3/` is a complete, byte-preserved snapshot of the seven files in the upstream [Fiber photometry V4_3 directory](https://github.com/superdongping/SongLabDLC/tree/ae3acb63b449573e144cf834eba5a9c959695c6a/Fiber%20photometry%20V4_3).

- Repository: `superdongping/SongLabDLC`
- Pinned upstream commit: `ae3acb63b449573e144cf834eba5a9c959695c6a`
- Retrieval and individual file hashes: [source_manifest.json](source_manifest.json)
- Principal ancestors of V1.0: `fiber_photometry_video_sync_v4_6.m` and `fiber_photometry_behavior_analysis_combined_sorted_V1_3.m`.

V1.0 adds project management, multi-ROI viewing, numbered behavior definitions, keyboard annotation, independent dual Y-axes, efficient video playback, event-table navigation and animal-level group analysis. Its active code is at the repository root and in `+fp/`.

The archive retains original comments, paths and limitations as historical source text. It is not the supported entry point. Do not add this directory recursively to the MATLAB path. No experimental data is included.

The original SongLabDLC directory remains available. This archive transfers the historical source snapshot into the new repository without deleting the original or rewriting its Git history.
